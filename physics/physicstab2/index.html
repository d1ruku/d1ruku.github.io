§84. Первый закон термодинамики

Закон сохранения энергии
Энергия в природе не возникает из ничего и не исчезает: её количество неизменно, она лишь переходит из одной формы в другую.

Первый закон термодинамики — частный случай закона сохранения энергии. Он показывает, от каких причин зависит изменение внутренней энергии тела.

Формулировка

Изменение внутренней энергии системы при переходе из одного состояния в другое равно сумме работы внешних сил и количества теплоты, переданной системе:

ΔU = A + Q    (13.11)

Если рассматривается работа системы над внешними телами (A′ = −A), формулу записывают иначе:

Q = ΔU + A′    (13.12)

Теплота, переданная системе, идёт на изменение её внутренней энергии и на совершение системой работы над внешними телами.

Изолированная система

Если A = 0 и Q = 0, то ΔU = 0, значит U₁ = U₂. Внутренняя энергия изолированной системы сохраняется.

Следствие — вечный двигатель 1-го рода невозможен
Если Q = 0, то A′ = −ΔU. Как только запас внутренней энергии исчерпан — двигатель останавливается.

§85. Применение первого закона к различным процессам

Процесс Условие Формула (из 13.12) Вывод
Изохорный
(V = const)		 A′ = 0
(работа = 0)		 ΔU = Q  (13.13) Вся теплота идёт на изменение внутренней энергии
Изотермический
(T = const)		 ΔU = 0
(U не меняется)		 Q = A′  (13.14) Вся теплота идёт на совершение работы
Изобарный
(p = const)		 — Q = ΔU + pΔV Теплота → и на ΔU, и на работу против постоянного давления
Адиабатный
(без теплообмена)		 Q = 0 A′ = −ΔU Работа совершается за счёт убыли внутренней энергии; расширение → охлаждение, сжатие → нагрев
Запомни — адиабатный процесс
Процесс, происходящий без теплообмена с окружающей средой, называется адиабатным. Удельная теплоёмкость при адиабатном процессе равна нулю (Q = 0). Примеры: накачка велосипедной шины, дизельный двигатель, распространение звуковых волн.

На графике p(V) адиабата располагается круче изотермы: при адиабатном расширении температура падает, поэтому давление убывает быстрее, чем при изотермическом расширении.

Вопросы и ответы
Стр. 278 — вопросы 1, 2, 4
1.
Как формулируется первый закон термодинамики?
Ответ
Изменение внутренней энергии системы при переходе из одного состояния в другое равно сумме работы внешних сил над системой и количества теплоты, переданной системе: ΔU = A + Q. В другой записи: количество теплоты, полученное системой, расходуется на изменение её внутренней энергии и на работу системы над внешними телами: Q = ΔU + A′.
2.
В каком случае изменение внутренней энергии отрицательно?
Ответ
ΔU < 0, когда система отдаёт больше энергии, чем получает: при охлаждении (Q < 0) и/или когда система совершает работу (A′ > 0), превышающую полученную теплоту. Например, при адиабатном расширении: Q = 0, поэтому A′ = −ΔU, то есть ΔU < 0 — газ охлаждается.
4.
Можно ли считать систему изолированной, если её температура остаётся постоянной?
Ответ
Нет. Постоянство температуры означает лишь, что внутренняя энергия не изменяется (ΔU = 0, как при изотермическом процессе). Но система может при этом обмениваться теплотой с окружающей средой и совершать работу (Q = A′ ≠ 0). Изолированная система — та, где A = 0 и Q = 0 одновременно.
Стр. 281 — вопросы 1, 2, 3
1.
В каком случае работа газа больше: при изотермическом расширении от V₁ до V₂ или при изобарном расширении от V₁ до V₂?
Ответ
При изобарном расширении. Работа газа равна площади фигуры под графиком p(V). При изобарном процессе давление остаётся постоянным (прямоугольная полоса), тогда как при изотермическом — давление убывает по гиперболе, и площадь под ней меньше. Следовательно, A′изобарный > A′изотермический.
2.
Как можно изменить температуру газа?
Ответ
Двумя способами (по первому закону термодинамики): 1) передать газу теплоту или отнять её (теплообмен); 2) совершить работу над газом или дать газу совершить работу (механическое воздействие — например, адиабатное сжатие/расширение). Температура — характеристика внутренней энергии, а она меняется под действием обоих факторов.
3.
Какой из процессов является самым выгодным для получения максимальной механической работы при данном количестве затраченной теплоты?
Ответ
Изотермический процесс. При T = const внутренняя энергия идеального газа не меняется (ΔU = 0), поэтому вся подведённая теплота целиком превращается в работу: Q = A′. В любом другом процессе часть теплоты расходуется на изменение внутренней энергии (нагрев газа), и работы получается меньше.
