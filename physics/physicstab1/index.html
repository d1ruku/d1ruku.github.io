01
Основные определения
🌡️ Агрегатные состояния
Вещество может находиться в трёх состояниях: твёрдом, жидком и газообразном. В термодинамике их называют фазами.
🔄 Фазовый переход
Переход системы из одного состояния (фазы) в другое. При переходах первого рода (плавление, испарение) происходит поглощение или выделение теплоты.
🔥 Теплообмен
Процесс передачи энергии от одного тела к другому без совершения работы. Количественная мера изменения внутренней энергии — количество теплоты Q.
⚖️ Уравнение теплового баланса
В изолированной системе суммарное количество теплоты равно нулю: Q₁ + Q₂ + Q₃ + … = 0. Отданная теплота — отрицательна, полученная — положительна.
⭐ Запомни
Удельная теплоёмкость c — количество теплоты, которую получает или отдаёт вещество массой 1 кг при изменении температуры на 1 К. Единица: Дж/(кг·К).
⭐ Запомни
Удельная теплота парообразования r — теплота, необходимая для превращения жидкости массой 1 кг в пар при постоянной температуре. Единица: Дж/кг.
⭐ Запомни
Удельная теплота плавления λ — теплота для превращения кристаллического тела массой 1 кг в жидкость при температуре плавления. Единица: Дж/кг.
02
Формулы
Процесс Формула Обозначения
Нагревание / охлаждение Q = cm(t₂ − t₁) c — уд. теплоёмкость, m — масса, Δt — изм. температуры
Парообразование (кипение) Qп = rm r — уд. теплота парообразования
Конденсация Qк = −rm Теплота выделяется → знак минус
Плавление Qпл = λm λ — уд. теплота плавления
Кристаллизация Qкр = −λm Теплота выделяется → знак минус
Тепловой баланс системы Q₁ + Q₂ + … = 0 Для изолированной системы

📌 Важно
К фазовым переходам первого рода относятся плавление и кристаллизация, испарение и конденсация. Температура вещества при этих переходах не меняется, хотя теплота поглощается или выделяется.

04
Разобранные задачи
Задача 1
Лёд + пар в калориметре (§83, Задача 1)
В калориметре находится лёд массой 1 кг при температуре t₁ = −40 °С. В калориметр пускают пар массой 1 кг при температуре t₂ = 120 °С. Определите установившуюся температуру и фазовое состояние системы.
cл = 2,1·10³, cв = 4,2·10³, cп = 2,2·10³ Дж/(кг·К); λл = 3,3·10⁵ Дж/кг; rп = 2,26·10⁶ Дж/кг.
mл = mп
1 кг каждый
tл
−40 °С
tп
120 °С
✏️ Решение
1
Теплота, которую может отдать пар: охладиться до 100°С + конденсироваться:
|Qотд| = cп·m·(120−100) + r·m = 2,2·10³·1·20 + 2,26·10⁶·1 ≈ 23,0·10⁵ Дж
2
Теплота, необходимая льду: нагреться до 0°С + растаять:
Qпол = cл·m·(0−(−40)) + λ·m = 2,1·10³·1·40 + 3,3·10⁵·1 ≈ 4,14·10⁵ Дж
3
Поскольку |Qотд| > Qпол, лёд полностью тает. Вода из льда может нагреться до 100°С:
Q'пол = cв·m·100 = 4,2·10³·1·100 = 4,2·10⁵ Дж
Суммарно вода из льда получает до 100°С: QполΣ = 8,34·10⁵ Дж.
4
Т.к. QполΣ < |Qотд| — не весь пар конденсируется. Масса оставшегося пара:
m'п = (|Qотд| − QполΣ) / r = (23,0 − 8,34)·10⁵ / 2,26·10⁶ ≈ 0,65 кг
Ответ: В калориметре установится t = 100 °С. Пара останется 0,65 кг, воды — 1,35 кг.
Задача 2
Нагрев воды у основания водопада (§83, Задача 2)
На сколько температура воды у основания водопада высотой h = 1200 м больше, чем у его вершины? На нагрев воды затрачивается η = 70% выделившейся энергии. Удельная теплоёмкость воды cв = 4200 Дж/(кг·К).
h
1200 м
η
0,70
cв
4200 Дж/(кг·К)
g
10 м/с²
✏️ Решение
1
При ударе воды у основания часть потенциальной энергии идёт на нагрев:
η·m·g·h = m·cв·Δt
2
Масса сокращается, выражаем Δt:
Δt = η·g·h / cв = 0,70 × 10 × 1200 / 4200 = 2,0 °С
Ответ: Вода у основания водопада теплее на Δt ≈ 2,0 °С.
Задача 3
Вода и лёд в калориметре — равновесие
В калориметре находится вода массой 0,4 кг при температуре 10 °С. В воду положили лёд массой 0,6 кг при температуре −40 °С. Какая температура установится, если теплоёмкость калориметра ничтожно мала?
cл = 2100 Дж/(кг·К); cв = 4200 Дж/(кг·К); λ = 3,3·10⁵ Дж/кг.
mв
0,4 кг, t = 10 °С
mл
0,6 кг, t = −40 °С
✏️ Решение
1
Теплота, которую может отдать вода (охладившись до 0°С):
Qв = cв·mв·10 = 4200·0,4·10 = 16 800 Дж
2
Теплота, необходимая льду только для нагрева до 0°С:
Qнагр = cл·mл·40 = 2100·0,6·40 = 50 400 Дж
3
Вода отдаёт меньше, чем нужно льду даже на нагрев: 16 800 < 50 400.
Значит, лёд не дотает — система остановится, когда вся вода замёрзнет и лёд нагреется до одной температуры t < 0 °С. Пишем тепловой баланс:
cв·mв·(t − 10) + cл·mл·(t − (−40)) = 0
4
Раскрываем: 4200·0,4·(t−10) + 2100·0,6·(t+40) = 0
1680t − 16800 + 1260t + 50400 = 0
2940t = −33600  ⟹  t ≈ −11,4 °С
(При t < 0 вода замёрзла — это согласованно.)
Ответ: В калориметре установится температура t ≈ −11 °С; вся вода перейдёт в лёд.
