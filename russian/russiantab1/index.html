1

Виды числительных

Количественные
  • Целые: один, пять, сто
  • Дробные: одна пятая, полтора
  • Собирательные: двое, трое
Порядковые
  • Первый, второй, третий
  • Склоняются как прилагательные
  • В составных — только последнее
Простые / Составные
  • Простые: одно слово (семь)
  • Сложные: одна основа (семьдесят)
  • Составные: несколько слов
Собирательные
  • Двое, трое … десятеро
  • Только с лицами м.р. и детьми
  • Нельзя: двое подруг ✗

6

Ключевые морфологические правила

  1. Оба / обе: оба — с существительными м. и ср. рода; обе — с существительными ж. рода. Р.п.: обоих / обеих.
  2. Полтора / полторы: с существительными м. и ср. рода — полтора (полтора часа), с ж. рода — полторы (полторы минуты). Все косвенные падежи: полутора.
  3. Дробные числительные управляют Р.п. ед.ч.: одна пятая метра; но полтора метра, полтора часа.
  4. Собирательные (двое, трое…) не употребляются с существительными ж.р.: двое друзей ✓ — двое подруг ✗.
  5. Тысяча, миллион, миллиард — существительные, поэтому управляют падежом: пяти тысячам, о миллионе.
  6. 40, 90, 100 имеют только две формы: И./В.п. — сорок, девяносто, сто; все остальные падежи — сорока, девяноста, ста.
  7. В составных числительных склоняется каждое слово: пятьюстами сорока пятью рублями.

8

Советы для запоминания

🔑
40 · 90 · 100 Только две формы: И./В. — сорок/девяносто/сто. Все остальные — сорока/девяноста/ста.
✂️
Сложные: склоняй обе части Пятьюстами (не пятьсот-ами). Тренируй по схеме: 1-я часть + 2-я часть.
♀
Женский род — особый Обе (не оба), полторы (не полтора), две подруги (не двое подруг).
📅
Год: склоняй последнее «В две тысячи двадцать пятом году» — только «пятом» меняется, остальное остаётся в И.п.
🧮
Полтора → полутора В любом косвенном падеже кроме В.п. говорим «полутора»: нет полутора метра.
👥
Собирательные — только м.р. Двое/трое друзей ✓, двое детей ✓ — но только не с существительными ж.р.!
