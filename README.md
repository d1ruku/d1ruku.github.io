# Строение клетки — §16–17
**Биология 10 класс · §16 Клеточная мембрана. Цитоплазма · §17 Рибосомы. Ядро. ЭПС**

---

| Часть клетки / Органоид | Строение | Функции |
|---|---|---|
| **Плазматическая (клеточная) мембрана** | Двойной слой фосфолипидов (бислой, 6–10 нм). Встроены белки: погружённые и пронизывающие. Снаружи — углеводные цепочки. | 1. Отграничивает клетку от среды и поддерживает её форму. 2. Защищает от механических и биологических воздействий. 3. Регулирует обмен веществ с внешней средой. 4. Рецепция — восприятие гормонов, антигенов. 5. Участвует в межклеточных контактах. 6. Обеспечивает эндо- и экзоцитоз. |
| **Клеточная стенка** | У растений — целлюлоза (полимер глюкозы). У грибов — хитин (N-ацетилглюкозамин). Жёсткая, пронизана порами. | 1. Поддерживает форму клетки. 2. Механическая защита. 3. Контакты между клетками через поры (цитоплазматические мостики). |
| **Гликокаликс** | Наружный слой животной клетки: молекулы гликолипидов и гликопротеинов, присоединённых к мембране. | 1. Объединение клеток в ткани. 2. Рецепция внешних сигналов. 3. Место работы ферментов (кишечный эпителий). 4. Защита мембраны. |
| **Цитоплазма (гиалоплазма)** | Полужидкая внутренняя среда клетки. Состоит из гиалоплазмы (основного вещества), органоидов и клеточных включений. Может менять вязкость. | 1. Перемещение веществ и органоидов внутри клетки. 2. Среда для биохимических реакций. 3. Определяет тургорное давление (совместно с вакуолями). |
| **Цитоскелет** | Сеть белковых нитей и трубочек, без мембран. Три компонента: микрофиламенты (актин), микротрубочки (тубулин), промежуточные филаменты. | 1. Поддерживает форму клетки. 2. Определяет расположение органоидов. 3. Обеспечивает движение клетки и органоидов. 4. Участвует в эндо- и экзоцитозе. |
| **Клеточный центр (центриоли)** | Два центриоля — цилиндры из микротрубочек под прямым углом друг к другу. Каждый центриоль: 9 групп по 3 микротрубочки. Без мембраны. | 1. Построение цитоскелета. 2. Формирование веретена деления при митозе и мейозе. |
| **Рибосомы** | Небольшие шаровидные органоиды из белков и РНК. Две субъединицы: большая и малая. Прокариоты: 15–20 нм, эукариоты: 25–30 нм. Без мембраны. | 1. Синтез белков. 2. На шЭПС — белки для мембран и выноса из клетки. 3. В цитоплазме — белки для внутреннего использования. |
| **Ядро и ядрышко** | Ядерная оболочка из 2 мембран с порами. Внутри — кариоплазма, хроматин (ДНК + белки-гистоны). Ядрышко — участок хромосомы с генами рРНК. | 1. Хранение наследственной информации (ДНК). 2. Передача и реализация наследственной информации. 3. Регуляция синтеза белков. 4. Ядрышко: синтез рРНК и сборка субъединиц рибосом. |
| **Эндоплазматическая сеть (ЭПС)** | Система каналов, ограниченных фосфолипидной мембраной. Шероховатая (с рибосомами, у ядра) и гладкая (без рибосом, дальше от ядра). | 1. Шероховатая: синтез и транспорт белков, компоненты для мембран. 2. Гладкая: синтез жиров, углеводов, половых гормонов. 3. Обезвреживание ядовитых веществ (гладкая). 4. Сборка клеточных мембран. |

---

## Ключевые термины

**§16:** клеточная стенка · плазматическая мембрана · гликокаликс · эндоцитоз (фагоцитоз, пиноцитоз) · экзоцитоз · рецепция · гиалоплазма · цитоскелет · клеточный центр · центриоли

**§17:** рибосомы · ядро · ядерная оболочка · кариоплазма · хроматин · гистоны · хромосомы · ядрышко · ЭПС шероховатая и гладкая
