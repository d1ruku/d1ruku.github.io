11
Возрастающие и убывающие функции
Задание 11
Определить монотонность функции y = logax
Какие из указанных функций являются возрастающими, а какие убывающими:
а) y = log3/11x ;   б) y = log7x ;   в) y = log6,7x ;   г) y = log0,03x
📌 Правило
Если основание a > 1 → функция возрастающая.
Если 0 < a < 1 → функция убывающая.
а) log3/11x
Основание: 3/11 ≈ 0,27 → 0 < a < 1
↘ Убывающая
б) log7x
Основание: 7 → a > 1
↗ Возрастающая
в) log6,7x
Основание: 6,7 → a > 1
↗ Возрастающая
г) log0,03x
Основание: 0,03 → 0 < a < 1
↘ Убывающая
✅ Ответ
Возрастающие: б), в)  |  Убывающие: а), г)
12
Принадлежность точки графику
Задание 12
Принадлежит ли точка графику y = log3x ?
Точка принадлежит графику y = log3x, если при подстановке x-координаты получается y-координата.
Проверяем: 3y = x.
📌 Метод
Подставляем x в формулу y = log3x. Если результат совпадает с y-координатой точки → точка принадлежит графику.
а) A(81; 3)
y = log381 = log334 = 4 ≠ 3
✗ Не принадлежит
б) B(1/81; −4)
y = log3(1/81) = log33−4 = −4 ✓
✓ Принадлежит
в) C(9√3; 2,5)
9√3 = 3² · 31/2 = 32,5
y = log332,5 = 2,5 ✓
✓ Принадлежит
г) D(√3/27; 2,5)
√3/27 = 31/2/33 = 3−5/2
y = log33−2,5 = −2,5 ≠ 2,5
✗ Не принадлежит
✅ Ответ
Графику принадлежат точки Б и В.
13
Нахождение основания и проверка точки
Задание 13
График y = logax проходит через (49; 4). Проверить точки.
Дано: граф y = logax проходит через (49; 4).
Найти основание a, затем проверить, проходит ли график через точки A и B.
Нахождение основания a
loga49 = 4  ⟹  a4 = 49
a4 = 49 = 7²  ⟹  a² = 7  ⟹  a = √7
(a > 0, a ≠ 1; √7 ≈ 2,646 — подходит)
Основание: a = √7
а) A(343; −6)
343 = 7³ = (√7)6
log√7(√7)6 = 6 ≠ −6
✗ Не проходит
б) B(49√7; 5)
49√7 = 7² · 71/2 = 75/2 = (√7)5
log√7(√7)5 = 5 ✓
✓ Проходит
✅ Ответ
Основание a = √7. Через точку B(49√7; 5) — проходит. Через A(343; −6) — не проходит.
14
Сравнение значений логарифмов
Задание 14
Сравнить значения выражений
📌 Правила сравнения
При a > 1: функция возрастает → больший аргумент = больший логарифм.
При 0 < a < 1: функция убывает → больший аргумент = меньший логарифм.
loga1 = 0 для любого a. Если x > 1 и a > 1 → log > 0. Если 0 < x < 1 и a > 1 → log < 0.
а) log46,01 и log46,001
Осн. a = 4 > 1 → функция возрастает.
6,01 > 6,001 → log46,01 > log46,001
log₄6,01 > log₄6,001
б) log1/80,37 и log1/80,24
Осн. a = 1/8 < 1 → функция убывает.
0,37 > 0,24 → log1/80,37 < log1/80,24
log₍₁/₈₎0,37 < log₍₁/₈₎0,24
в) log0,12,7 и log0,12,8
Осн. a = 0,1 < 1 → функция убывает.
2,7 < 2,8 → log0,12,7 > log0,12,8
log₀,₁2,7 > log₀,₁2,8
г) log549 и 0
Осн. 5 > 1; аргумент 49 > 1
→ логарифм положителен
log₅49 > 0
д) log0,0927 и 0
Осн. 0,09 < 1; аргумент 27 > 1
→ логарифм отрицателен
log₀,₀₉27 < 0
е) lg 9 и 0
lg = log10; осн. 10 > 1; аргумент 9 > 1
→ логарифм положителен
lg 9 > 0
15
Область определения функции
Задание 15
Найти область определения
📌 Условия ОДЗ для логарифма
Для logaf(x): нужно f(x) > 0.
Для logg(x)f(x): нужно f(x) > 0 И g(x) > 0 И g(x) ≠ 1.
а) y = log11(7 − 9x)
Условие: 7 − 9x > 0
−9x > −7
x < 7/9
D(y) = (−∞; 7/9)
б) y = log0,3((3x−1)/(6−x))
Условие: (3x−1)/(6−x) > 0
Нули: x = 1/3 и x = 6
Метод интервалов: оба знаменатель и числитель одного знака
  x < 1/3: (−)(+)/(+) → отриц. ✗
  1/3 < x < 6: (+)/(+) → полож. ✓
  x > 6: (+)/(−) → отриц. ✗
D(y) = (1/3; 6)
в) y = log7(3 + 5x − 2x²)
Условие: 3 + 5x − 2x² > 0
2x² − 5x − 3 < 0
D = 25 + 24 = 49; корни: x = (5±7)/4
x₁ = −1/2, x₂ = 3
Парабола ветвями вверх → между корнями
D(y) = (−1/2; 3)
г) y = logx−2(x² − 5)
Условие 1: x − 2 > 0 → x > 2
Условие 2: x − 2 ≠ 1 → x ≠ 3
Условие 3: x² − 5 > 0 → x < −√5 или x > √5
Пересечение: x > 2 и x > √5 ≈ 2,24 и x ≠ 3
→ x > √5 и x ≠ 3
D(y) = (√5; 3) ∪ (3; +∞)

y = log4x  (основание a = 4 > 1)
Осн.: a = 4 > 1
Монот.: возрастает на (0; +∞)
ОДЗ: x > 0
Асимп.: x = 0 (вертикальная)
Через: (1; 0), (4; 1), (1/4; −1)
y = log0,1x  (основание 0 < a < 1)
Осн.: a = 0,1 < 1
Монот.: убывает на (0; +∞)
ОДЗ: x > 0
Асимп.: x = 0 (вертикальная)

✦ Сравнение двух графиков
Оба графика проходят через точку (1; 0) и имеют вертикальную асимптоту x = 0.
y = log4x — возрастает (ветвь вправо-вверх).
y = log0,1x — убывает (ветвь вправо-вниз). Это зеркальное отражение возрастающей функции относительно оси x.
