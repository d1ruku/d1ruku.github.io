§7
Ароматические углеводороды (Арены). Бензол.
🔷 Ароматические углеводороды (арены)
Углеводороды, в молекулах которых содержится бензольное кольцо. Общая формула: CnH2n−6. Имеют характерный запах.
⬡ Бензол C₆H₆
Первый представитель аренов. Бесцветная жидкость со специфическим запахом. Нерастворим в воде, лучше воды. Хороший органический растворитель. Очень ядовит!
🔬 Строение бензола (Кекуле)
Шесть атомов C образуют замкнутый цикл. Все C–C связи одинаковы — полуторные (промежуточные между одинарными и двойными). Обозначается шестиугольником с кружком внутри.
⚠️ Фенил C₆H₅–
Одновалентный радикал бензола. Образуется при реакции замещения (например, бромирование бензола даёт бромбензол C₆H₅Br).
⭐ Гомологический ряд аренов
C₆H₆ (бензол) → C₆H₅–CH₃ (толуол / метилбензол) → C₆H₅–C₂H₅ (этилбензол) → … Общая формула: CnH2n–6, где n ≥ 6
📌 Химические свойства бензола
Для бензола характерны реакции замещения (а не присоединения, как у алкенов).
🧪 Реакция бромирования (замещение) C₆H₆ + Br₂ → кат. → C₆H₅Br + HBr
(образуется бромбензол или фенилбромид)
🧪 Реакция нитрования C₆H₆ + HNO₃ → кат. (H₂SO₄) → C₆H₅–NO₂ + H₂O
(образуется нитробензол — первый шаг к получению анилина)
🔥 Горение бензола 2C₆H₆ + 15O₂ → 12CO₂ + 6H₂O
(горит коптящим пламенем из-за высокой доли углерода)
☣️ Применение бензола
Сырьё для синтеза: красители, ядохимикаты, пластмассы, моющие средства, лекарства, ацетон, анилин, добавка к топливу. Бензол очень ядовит — использование ограничено!
📌 Экстракция
Извлечение вещества из раствора с помощью второго растворителя, не смешивающегося с первым, называют экстракцией. Бензол — хороший экстрагент.

§8
Природный газ
🌿 Состав природного газа
Смесь предельных углеводородов и неорганических газов. Преобладает метан CH₄ (88–95%). Образовался из органических остатков без доступа воздуха.
🔥 Попутный нефтяной газ
Содержит больше этана, пропана, бутана, пентана. Делится на фракции: газовый бензин (C₅–C₆), пропан-бутановая фракция (сжиженный газ), сухой газ (≈ природный газ).

⭐ Преимущества природного газа как топлива
1) Дешевизна — самый экономичный вид топлива
2) Высокая теплотворная способность
3) Лёгкость транспортировки (по газопроводам)
4) Экологичность — минимальные вредные выбросы при сгорании
🔥 Горение метана CH₄ + 2O₂ → CO₂ + 2H₂O
(горит бесцветным пламенем)
📌 Химическая переработка природного газа
Конверсия — взаимодействие метана с перегретым водяным паром:
CH₄ + H₂O → CO + 3H₂  (синтез-газ)

Пиролиз — нагревание без доступа воздуха → углерод (сажа), водород, ацетилен.

§9
Нефть и способы её переработки
🛢️ Нефть
Маслянистая жидкость от светло-коричневого до тёмно-бурого цвета со специфическим запахом. Природная смесь углеводородов (C₆–C₅₀), главным образом алканов линейного и разветвлённого строения. Нерастворима в воде.
⛽ Ректификация (перегонка)
Разделение жидких смесей на фракции — компоненты с близкими температурами кипения. Проводится в ректификационных колоннах. Физический процесс — химических реакций нет.
⚗️ Крекинг
Термическое расщепление углеводородов с получением продуктов с меньшей молярной массой. Впервые промышленный крекинг — В. Г. Шухов, 1891 г. Бензин крекинга — невысокого качества.
🔄 Риформинг
Переработка нефтепродуктов с целью повышения качества бензина и получения ароматических углеводородов. Два типа реакций: изомеризация предельных углеводородов и их дегидрирование.
⭐ Октановое число
Количественный показатель детонационной устойчивости бензина. Эталоны шкалы:
• н-гептан C₇H₁₆ → октановое число = 0
• изооктан (2,2,4-триметилпентан) C₈H₁₈ → октановое число = 100
Бензин АИ-95 имеет детонационную устойчивость как смесь 95% изооктана и 5% н-гептана.

Задание 2(в)
Уравнения реакций цепочки превращений
Напишите уравнения реакций, с помощью которых можно осуществить следующие превращения:

в) CH₄ → CO → CnH2n+2
✏️ Решение — Шаг 1: CH₄ → CO
1
Первое превращение — конверсия метана (взаимодействие с перегретым водяным паром):
CH₄ + H₂O  →кат., t→  CO + 3H₂
Продукт — синтез-газ (CO + H₂ в соотношении 1:3)
✏️ Решение — Шаг 2: CO → CnH2n+2
2
Второе превращение — синтез алканов из синтез-газа (реакция Фишера–Тропша, промышленное получение синтетического бензина):
nCO + (2n+1)H₂  →кат.→  CnH2n+2 + nH₂O
Образуются предельные углеводороды — алканы (синтетический бензин)
📋 Итоговая схема
→
CH₄ + H₂O  кат., t  → CO + 3H₂
nCO + (2n+1)H₂  кат.  → CnH2n+2 + nH₂O
Вывод: Цепочка CH₄ → CO → CnH2n+2 осуществляется через конверсию метана (получение синтез-газа CO + H₂) и последующий синтез Фишера–Тропша (получение алканов из синтез-газа). Это промышленный способ получения синтетического топлива.
