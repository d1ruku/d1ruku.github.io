Цепочки превращений (готовое решение)
Составьте уравнения реакций для цепочек превращений:

а) этан → этилен → этиловый спирт → уксусный альдегид
б) метан → хлорметан → метиловый спирт → метиловый эфир уксусной кислоты
в) этиловый спирт → этилен → бромэтан → этиловый спирт → этилат калия
а) Этан → этилен → этиловый спирт → уксусный альдегид
1
Дегидрирование этана (отщепляем водород):
CH3–CH3 → CH2=CH2 + H2
2
Гидратация этилена (добавляем воду):
CH2=CH2 + H2O → CH3–CH2–OH
3
Окисление спирта (оксид меди):
CH3–CH2–OH + CuO → CH3–CHO + Cu + H2O
б) Метан → хлорметан → метиловый спирт → метиловый эфир уксусной кислоты
1
Хлорирование метана (на свету):
CH4 + Cl2 → CH3Cl + HCl
2
Получение спирта (реакция со щелочью, водный р-р):
CH3Cl + NaOH → CH3OH + NaCl
3
Этерификация (спирт + уксусная кислота):
CH3OH + CH3COOH → CH3COOCH3 + H2O
в) Этиловый спирт → этилен → бромэтан → этиловый спирт → этилат калия
1
Дегидратация спирта (отнимаем воду):
CH3–CH2–OH → CH2=CH2 + H2O
2
Гидробромирование (добавляем HBr):
CH2=CH2 + HBr → CH3–CH2Br
3
Гидролиз бромэтана (водный р-р KOH):
CH3–CH2Br + KOH → CH3–CH2–OH + KBr
4
Образование алкоголята (реакция с чистым калием):
2CH3–CH2–OH + 2K → 2CH3–CH2–OK + H2
Итог: цепочки превращений оформлены в три блока (а–в) с полными уравнениями и условиями реакций.
